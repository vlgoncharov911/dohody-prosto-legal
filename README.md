# dohody-prosto-legal

Публичные страницы Prosto Studio: приложение «Доходы Просто» и игра «Стрелки».

Это статический сайт для GitHub Pages. Он не является юридическим документом сам по себе: юридическая сила у утверждённых исходных текстов.

## Состав

- `demo/` — документы «Доходы Просто — Демо»
- `main/` — актуальный публичный legal-пакет основной версии «Доходы Просто»
- `main/archive/` — предыдущие зафиксированные редакции правовых документов
- `apps/dohody-prosto/` — продуктовая страница приложения
- `apps/strelki/` — продуктовая страница игры «Стрелки»
- `games/` — раздел «Игры» с карточкой «Стрелки»
- `games/strelki/` — актуальные документы «Стрелки» для приложения 1.0.0; у каждого документа своя версия
- `games/strelki/archive/` — предыдущие редакции документов «Стрелки»

Текущая версия приложения на `/main/` и на странице приложения: **1.0.2**.

## Правило правок

Юридические тексты нельзя менять в website layer без обновления их исходных утверждённых копий.

Не добавлять в HTML юридические положения, контакты, магазины или формулировки, которых нет в исходном документе.

Сайт не меняет юридический смысл независимо от канонического источника.

## Технически

Обычный HTML и CSS. Нет npm, JavaScript, аналитики, cookie-диалогов, CDN и внешних запросов.
