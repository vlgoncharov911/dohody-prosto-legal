# dohody-prosto-legal

Публичные пользовательские правовые документы приложений «Доходы Просто».

Это статический сайт для GitHub Pages. Он не является юридическим документом сам по себе: юридическая сила у утверждённых исходных текстов.

## Состав

- `demo/` — документы «Доходы Просто — Демо»
- `main/` — задел под комплект основной версии «Доходы Просто» (пока только placeholder)

## Правило правок

Юридические тексты нельзя менять в website layer без обновления их исходных утверждённых копий.

Не добавлять в HTML юридические положения, контакты, магазины или формулировки, которых нет в исходном документе.

## Технически

Обычный HTML и CSS. Нет npm, JavaScript, аналитики, cookie-диалогов, CDN и внешних запросов.
