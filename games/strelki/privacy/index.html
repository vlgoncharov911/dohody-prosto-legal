1. Общие положения и Разработчик

Настоящая Политика конфиденциальности определяет порядок обработки данных при использовании мобильной игры «Стрелки».

Политика описывает, какие данные хранятся только на Устройстве, в каких случаях Персональные данные обрабатывает Разработчик и какие данные могут обрабатываться при взаимодействии Игры с внешними сервисами.

Сведения о внешних сервисах приводятся только в объёме, необходимом для описания взаимодействия Игры с ними.

2. Термины и определения

Политика — настоящая Политика конфиденциальности «Стрелки».

Игра — мобильное приложение «Стрелки».

Пользователь — физическое лицо, использующее Игру.

Данные аналитики — технические данные, необходимые для работы аналитики, и сведения о заранее определённых действиях в Игре.

Согласие на аналитику — отдельное согласие Пользователя на обработку Персональных данных для аналитики использования Игры с использованием MyTracker.

Термины, определённые в настоящем разделе, используются в Политике в указанном значении.

3. Локальное хранение

Прогресс хранится локально на Устройстве. Игра не создаёт собственных пользовательских аккаунтов, а Разработчик не использует собственный сервер или облачное хранилище для хранения Прогресса. Игра автоматически не передаёт Прогресс Разработчику. Пользователь может самостоятельно направить отдельные сведения из Прогресса или связанные с ним материалы в составе обращения; в таком случае их обработка осуществляется в порядке раздела 4.

Отдельные игровые события и ограниченные параметры могут передаваться MyTracker только при действующем Согласии на аналитику и только в объёме, указанном в разделе 6.

По действию Пользователя Игра может создать Резервную копию. Пользователь сам выбирает, куда сохранить файл. Передача такого файла выполняется только по решению Пользователя.

Для использования Игры не требуется создавать аккаунт у Разработчика или входить по электронной почте. Игра не запрашивает у Пользователя имя, номер телефона или возраст. Использование отдельных функций внешних сервисов, включая оформление Подписки Pro через RuStore, может требовать авторизации в соответствующем внешнем сервисе.

Локальная запись о принятии Пользовательского соглашения и ознакомлении с Политикой сохраняется на Устройстве и не передаётся Разработчику.

Решение Пользователя о Согласии на аналитику и о варианте рекламы сохраняется локально. Когда Игра запускает Yandex Mobile Ads SDK, она передаёт ему выбранный Пользователем режим рекламы.

Игра не позиционируется как приложение, специально предназначенное для детей, и не ведёт отдельный детский профиль.

4. Обращения Пользователя

При обращении Пользователя по электронной почте Разработчик обрабатывает адрес электронной почты отправителя, текст обращения, приложенные файлы и иные сведения, которые Пользователь самостоятельно направил в составе обращения.

Указанные данные обрабатываются для рассмотрения обращения, подготовки ответа и решения вопроса, указанного Пользователем.

Персональные данные, содержащиеся в обращении, обрабатываются в течение срока, необходимого для рассмотрения обращения, подготовки ответа и выполнения требований законодательства Российской Федерации.

5. Резервная копия

Резервная копия создаётся только по команде Пользователя и сохраняется в выбранное им место. Игра сама никуда этот файл не отправляет.

Файл не шифруется паролем. В него не входят сведения о Подписке Pro, о принятии документов, о Согласии на аналитику и о выборе варианта рекламы.

Восстановление из файла заменяет на этом Устройстве ту часть Прогресса, которая входит в Резервную копию. Согласие на аналитику и выбор рекламы при этом не меняются и из файла не восстанавливаются.

Какие сведения входят в файл, описано в справке «Данные, резервные копии и удаление».

После повторной установки отдельные локальные данные могут быть восстановлены средствами операционной системы, если системное резервное копирование было включено. Такая копия не является Резервной копией Игры.

6. Аналитика использования MyTracker

MyTracker используется для получения статистики установок, запусков и сессий, анализа прохождения уровней и использования основных функций Игры, а также улучшения Игры.

MyTracker запускается только при наличии сохранённого на Устройстве действующего Согласия на аналитику для редакции Согласия, требуемой текущей версией Игры.

Обновление Игры само по себе не означает нового Согласия. Если для установленной версии нужна новая редакция Согласия, MyTracker не запускается, пока Пользователь не решит заново.

Если Согласие на аналитику не предоставлено либо ранее предоставленное Согласие отозвано, MyTracker не инициализируется и новые Данные аналитики Игрой не передаются. Если MyTracker уже был инициализирован в текущем процессе Игры, после отзыва Согласия Игра выполняет перезапуск, после которого MyTracker не инициализируется до нового предоставления Согласия.

Для обработки Данных аналитики Разработчик использует сервис MyTracker ООО «ВК».

Игра не передаёт MyTracker координаты точного местоположения и не запрашивает разрешение на доступ к местоположению специально для аналитики.

Автоматическая передача сведений о покупках средствами MyTracker отключена.

Игра не передаёт MyTracker вручную Android ID и не задаёт собственный идентификатор Пользователя.

По событиям Игра передаёт только факт заранее определённых действий и короткие параметры:

  • старт уровня — режим, номер уровня, сложность;
  • победа — режим, номер уровня, сложность, длительность в секундах;
  • поражение — режим, номер уровня, сложность, длительность в секундах;
  • использование подсказки — режим, номер уровня, сложность, источник подсказки;
  • запрос ролика для продолжения уровня — режим, номер уровня, сложность, тип награды;
  • получение награды после такого ролика — режим, номер уровня, сложность, тип награды.

Кроме перечисленных выше параметров, в MyTracker не передаются иные сведения из Прогресса, имя, адрес электронной почты, тексты Пользователя, содержимое Резервной копии или иные произвольные данные Пользователя.

Полные условия согласия — в документе «Согласие на аналитику».

7. Реклама

Когда Pro не действует, для показа рекламы используется Yandex Mobile Ads SDK. Пока доступ Pro действует, реклама не показывается.

Пользователь отдельно разрешает персонализированную рекламу либо оставляет рекламу без персонализации. Когда Игра запускает Yandex Mobile Ads SDK, она передаёт ему выбранный Пользователем режим рекламы.

Выбор варианта рекламы не является Согласием на аналитику.

Игра не передаёт в Yandex Mobile Ads SDK координаты точного местоположения и не включает доступ к местоположению специально для показа рекламы.

При работе SDK с Устройства могут передаваться технические данные, необходимые для показа рекламы, включая рекламный идентификатор устройства, если он доступен и его использование разрешено настройками Устройства.

Игра не передаёт в Yandex Mobile Ads SDK Прогресс или содержимое Резервной копии.

Актуальные сведения о данных SDK опубликованы здесь:

  • Данные и конфиденциальность Yandex Mobile Ads SDK
  • Политика конфиденциальности Яндекса

8. RuStore и Подписка Pro

Игра распространяется через RuStore. Подписка Pro оформляется с использованием RuStore.

При оформлении и проверке Подписки Pro ООО «Много приложений» по поручению Разработчика обрабатывает сведения, необходимые для платежа и доступа.

Игра получает от RuStore сведения, необходимые для определения доступа Pro, включая идентификатор продукта, состояние подписки и срок действия доступа.

Номер банковской карты Разработчик не получает. Прогресс для оплаты не требуется и в RuStore не передаётся.

Официальный документ: Политика конфиденциальности RuStore.

Подробнее о доступе — в документе «Условия Pro».

9. Уведомления

Игра может напомнить о головоломке дня. Уведомление формируется локально средствами Игры на Устройстве из уже сохранённых результатов и не требует передачи Прогресса. Отключить напоминания можно в настройках Игры или Устройства.

10. Удаление данных

Прогресс и настройки хранятся локально. Пользователь может удалить или сбросить предусмотренные Игрой локальные данные средствами самой Игры либо очистить данные Игры средствами операционной системы.

Удаление локальных данных не отменяет Подписку Pro и не удаляет сведения, ранее переданные во внешние сервисы либо направленные Пользователем Разработчику.

Что именно удаляют функции Игры и что происходит при очистке данных Игры средствами операционной системы, описано в справке «Данные, резервные копии и удаление».

11. Права Пользователя

В случаях, когда Разработчик обрабатывает Персональные данные Пользователя, Пользователь вправе получить информацию об их обработке, потребовать уточнения, блокирования или удаления при наличии предусмотренных законом оснований, отозвать ранее предоставленное согласие и потребовать прекращения обработки в случаях, предусмотренных законодательством Российской Федерации.

Пользователь вправе не предоставлять Согласие на аналитику. Игра доступна без него.

Порядок предоставления и отзыва Согласия на аналитику установлен документом «Согласие на аналитику».

По вопросам обработки Персональных данных: DohodyProsto@yandex.ru.

Пользователь вправе обжаловать действия или бездействие Разработчика в Роскомнадзор или в суд.

12. Защита Персональных данных

Разработчик принимает необходимые правовые, организационные и технические меры для защиты обрабатываемых им Персональных данных от неправомерного или случайного доступа, изменения, предоставления, распространения, удаления и иных неправомерных действий.

13. Изменение Политики

Политика может обновляться при изменении Игры, порядка обработки данных или требований законодательства.

Актуальная редакция содержит номер версии документа, версию Игры, для которой она предназначена, и дату обновления.

Если изменение целей, состава или порядка обработки в соответствии с законодательством требует получения нового согласия, такое согласие запрашивается отдельно до начала соответствующей обработки. Установка обновления сама по себе такого согласия не даёт.
