Версия документа: 1.0

Для версии приложения: 1.0.0

Обновлено: 18 октября 2026 года

Игра содержит сторонние программные компоненты, распространяемые на условиях лицензий, приведённых ниже.

Apache License 2.0

На условиях Apache License 2.0 используются Kotlin, библиотеки AndroidX, включая Jetpack Compose, и kotlinx-coroutines.

Текст лицензии: Apache License 2.0.

Тесты сборки используют JUnit 4 на условиях Eclipse Public License 1.0. В приложение для игрока эта библиотека не входит.

MyTracker SDK 3.6.0

Используется в соответствии с Лицензионным соглашением сервиса MyTracker ООО «ВК».

В Maven Central для артефакта com.my.tracker:mytracker-sdk:3.6.0 также указана лицензия GNU LGPL 3.

  • Лицензионное соглашение MyTracker
  • GNU LGPL v3

Другие сторонние компоненты

В Игре используются Yandex Mobile Ads SDK для показа рекламы и RuStore Pay SDK для оформления Подписки Pro.

Эти компоненты используются на условиях соответствующих правообладателей. Их наличие в Игре само по себе не означает распространения на условиях лицензий открытого ПО.
