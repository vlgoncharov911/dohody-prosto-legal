Удаление данных «Доходы Просто»

Версия 1.0.5-main-draft · обновлено 26 августа 2026

1. Назначение документа

Настоящий документ определяет фактические последствия функции «Удалить данные приложения» в приложении «Доходы Просто».

Документ описывает, какие локальные данные этой установки Приложения удаляются, что сохраняется, что отключается и что происходит при следующем запуске Приложения.

Настоящий документ не изменяет Пользовательское соглашение, Политику конфиденциальности, Условия PRO и документ «Данные и резервные копии». Правила доступа к PRO, резервному копированию и восстановлению Данных учёта определяются указанными документами.

2. Термины и связанные документы

Термины Приложение, Пользователь, Разработчик, Устройство, FREE, PRO, Подписка PRO, RuStore, Данные учёта, Резервная копия, PIN-код, Биометрическая проверка и Идентификатор установки используются в значении, установленном Пользовательским соглашением и Политикой конфиденциальности.

Термины Внутренняя страховочная копия и Экспортированный файл используются в значении, установленном документом «Данные и резервные копии».

Настоящий документ применяется вместе с Пользовательским соглашением, Политикой конфиденциальности, Условиями PRO и документом «Данные и резервные копии».

Для использования Приложения не требуются регистрация, создание аккаунта или вход по электронной почте. Функция «Удалить данные приложения» не является удалением аккаунта Приложения.

3. Что делает функция «Удалить данные приложения»

Функция «Удалить данные приложения» удаляет локальные данные и настройки этой установки Приложения, прямо указанные в настоящем документе, не удаляя само Приложение.

Функция доступна в Настройках Приложения. Функция также может быть доступна с экрана блокировки входа после нескольких неудачных попыток ввода PIN-кода. Ошибочный ввод PIN-кода сам по себе не приводит к автоматическому удалению данных. Удаление выполняется только после отдельного подтверждения Пользователем.

До подтверждения удаления Пользователь при необходимости может создать Резервную копию, если соответствующая возможность доступна. При отсутствии подходящей Резервной копии восстановление удалённых Данных учёта средствами Приложения невозможно.

После успешного выполнения Приложение обновляет рабочие экраны, чтобы на них не оставались удалённые Данные учёта.

4. Какие локальные данные удаляются

Функция удаляет Данные учёта, хранящиеся внутри Приложения.

Функция также удаляет связанные локальные настройки учёта, включая настройки расчёта налога, целей, графика и начальных подсказок использования.

Функция удаляет локально сохранённые сведения о принятии Пользовательского соглашения этой установки и локально сохранённый выбор варианта рекламы.

Поэтому после удаления Приложение повторно запрашивает соответствующие действия при следующем запуске.

Функция удаляет локальные данные напоминаний Приложения, связанные с ранее существовавшими записями учёта.

5. Что происходит с PIN-кодом и Биометрической проверкой

Сохранённый PIN-код удаляется.

Использование Биометрической проверки для входа в Приложение отключается.

Приложение не получает, не хранит и не удаляет биометрические данные, хранимые операционной системой Устройства.

После выполнения функции защита входа в Приложение с использованием PIN-кода отсутствует, пока Пользователь не установит PIN-код снова, если соответствующая возможность доступна.

6. Что происходит с напоминаниями и фоновыми задачами

Уже запланированные локальные уведомления Приложения отменяются.

Уже показанные локальные уведомления Приложения снимаются.

Настройки локальных напоминаний внутри Приложения сбрасываются к исходным значениям Приложения.

Фоновые задачи Приложения, связанные с такими локальными напоминаниями, отменяются.

Разрешение операционной системы Устройства на показ уведомлений Приложением этим действием не отзывается.

После следующего запуска новые локальные напоминания могут быть сформированы только по новому состоянию Данных учёта и только если соответствующая возможность доступна.

7. Что происходит с резервным копированием

Внутренняя страховочная копия удаляется.

Автоматическое резервное копирование выключается.

Сохранённый пароль автоматического резервного копирования удаляется.

Выбранное в Приложении место хранения автоматических копий сбрасывается. Само место хранения вне Приложения и файлы в нём этим действием не удаляются.

Ранее выбранная частота автоматического резервного копирования не сохраняется.

8. Другие данные, которые не удаляются

Функция не удаляет:

  • само Приложение;
  • данные других приложений;
  • данные, которые Пользователь ранее самостоятельно направил Разработчику.

Функция не очищает Устройство и не заменяет удаление Приложения либо очистку данных Приложения средствами операционной системы Устройства.

9. Внешние Резервные копии и Экспортированные файлы

Резервные копии и Экспортированные файлы, сохранённые вне Приложения, остаются там, где их сохранил Пользователь. Пользователь управляет такими файлами самостоятельно.

Наличие внешнего файла само по себе не восстанавливает Данные учёта. Восстановление Данных учёта из подходящей Резервной копии выполняется отдельно, если соответствующая возможность доступна, в порядке, установленном документом «Данные и резервные копии» и Условиями PRO.

10. Подписка PRO

Использование функции «Удалить данные приложения» не отменяет Подписку PRO и не оформляет возврат платежа.

Доступ к PRO после выполнения функции определяется при последующей работе Приложения в том же порядке, что и при обычном запуске.

Резервная копия не подтверждает Подписку PRO.

11. Идентификатор установки

Идентификатор установки при использовании функции «Удалить данные приложения» сохраняется локально на Устройстве.

Идентификатор установки не является аккаунтом Пользователя.

Удаление Приложения или очистка его данных средствами операционной системы Устройства являются другими действиями и не относятся к функции «Удалить данные приложения».

12. Что происходит после следующего запуска

При следующем запуске Приложения Данные учёта этой установки отсутствуют, пока Пользователь не введёт новые данные либо не восстановит поддерживаемые Данные учёта из подходящей Резервной копии.

После удаления Приложение заново создаёт начальные категории каталога, предусмотренные текущей версией Приложения. Это не является восстановлением удалённых Данных учёта.

Защита входа в Приложение с использованием PIN-кода отсутствует, пока PIN-код не будет установлен снова.

Приложение снова запрашивает принятие Пользовательского соглашения и выбор варианта рекламы, если соответствующие сведения этой установки были удалены.

Автоматическое резервное копирование остаётся выключенным, пока Пользователь не включит его снова, если соответствующая возможность доступна.

13. Ограничения действия функции

Функция действует только в отношении локальных данных этой установки Приложения на Устройстве.

Средствами Приложения удалённые Данные учёта могут быть восстановлены только из подходящей Резервной копии, если такой файл доступен Пользователю и восстановление доступно в соответствии с документом «Данные и резервные копии» и Условиями PRO.
