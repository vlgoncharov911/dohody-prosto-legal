Использование данных в «Доходы Просто»

Версия 1.0.0-main-draft · обновлено 24 августа 2026

Подробнее: Политика конфиденциальности «Доходы Просто».

1. Основное

Ваши рабочие и финансовые данные хранятся на устройстве. Разработчик не получает содержимое рабочей базы учёта.

Для работы не нужен аккаунт. Резервную копию можно сохранить на устройстве или отправить через системное меню.

2. Что хранится на устройстве

Продажи, каталог, работы, оплаты, расходы, цели, данные для расчёта налога, график, аналитика и связанные настройки хранятся локально.

PIN-код используется для локальной защиты. Биометрию выполняет система устройства.

Напоминания создаются локально. Рабочие суммы не включаются в текст уведомлений.

3. Реклама и внешние сервисы

В бесплатной версии для рекламы может использоваться Yandex Mobile Ads SDK. Рабочие записи учёта в рекламный SDK не передаются. Геолокация для рекламы не используется. Используется AD_ID при его доступности.

Оплата PRO при оформлении подписки проходит через механизмы RuStore.

4. Резервные копии

Ручную копию можно сохранить на устройстве или выбрать «Отправить». Пароль копии не передаётся разработчику и не восстанавливается им.
