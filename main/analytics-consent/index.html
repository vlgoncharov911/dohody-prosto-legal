2. Термины

Термины Приложение, Пользователь, Разработчик, Устройство, Персональные данные, Данные учёта, Идентификатор установки, Рекламный идентификатор (AD_ID), FREE и PRO используются в значении, установленном Пользовательским соглашением и Политикой конфиденциальности «Доходы Просто».

3. Цели обработки

Пользователь предоставляет Согласие на обработку Данных аналитики для следующих целей:

  • улучшения и развития Приложения на основании статистики его использования;
  • определения источника установки Приложения;
  • оценки эффективности рекламных кампаний Приложения.

Настоящее Согласие не является согласием на персонализацию рекламы.

Выбор персонализированной рекламы или рекламы без персонализации осуществляется отдельно.

4. Какие данные могут обрабатываться

При наличии действующего Согласия MyTracker может обрабатывать технические данные, необходимые для работы аналитики и атрибуции в используемой конфигурации Приложения.

К ним относятся:

  • версия Приложения;
  • тип и модель Устройства;
  • версия операционной системы;
  • язык системы;
  • параметры экрана;
  • дата и время использования Приложения;
  • часовой пояс;
  • технические сведения о сетевом соединении;
  • сведения об операторе связи или интернет-провайдере;
  • IP-адрес;
  • User Agent;
  • Рекламный идентификатор (AD_ID), если он доступен MyTracker и его использование разрешено средствами операционной системы;
  • сведения об установке Приложения;
  • сведения о первом и последующих запусках Приложения;
  • сведения о сессиях и продолжительности использования Приложения.

Подробные актуальные сведения о технических данных, которые может обрабатывать MyTracker, содержатся в Политике конфиденциальности MyTracker. Фактический состав передаваемых данных зависит от используемой в Приложении конфигурации MyTracker и технических возможностей Устройства.

Точное местоположение Устройства средствами MyTracker в используемой конфигурации Приложения не отслеживается.

Приложение не передаёт MyTracker вручную Android ID.

Приложение не передаёт MyTracker собственный Идентификатор установки и не устанавливает для MyTracker собственный идентификатор Пользователя.

Автоматическая передача сведений о покупках средствами MyTracker отключена.

5. Какие действия в Приложении учитываются

При наличии действующего Согласия Приложение может передавать в MyTracker только сведения о самом факте совершения заранее определённых действий.

К таким действиям относятся:

  • создание продажи;
  • создание работы;
  • завершение работы;
  • создание оплаты по работе;
  • создание расхода;
  • установка или изменение цели месяца;
  • первое включение хотя бы одной налоговой категории после успешного сохранения настроек налогов;
  • открытие раздела «Вся история»;
  • переход на экран Календаря;
  • успешное сохранение графика рабочих дней;
  • открытие полной карточки Аналитики, доступной Пользователю;
  • открытие экрана «Доходы Просто PRO»;
  • фактическое начало сценария покупки PRO;
  • подтверждение успешной покупки PRO.

Открытие истории из отдельной карточки или другого ограниченного контекста не считается открытием раздела «Вся история».

Простое открытие редактора графика рабочих дней не считается использованием функции настройки графика. Событие учитывается только после успешного сохранения графика.

Если Пользователю недоступна карточка Аналитики и при нажатии открывается экран PRO, такое действие не считается использованием Аналитики.

Приложение не передаёт в MyTracker параметры или содержание указанных действий.

11. Техническое соблюдение решения Пользователя

Архитектура Приложения не должна допускать передачу Данных аналитики в MyTracker при отсутствии действующего Согласия.

Приложение сначала успешно сохраняет на Устройстве факт предоставления Согласия и только после этого получает право выполнить инициализацию MyTracker.

Если текущая версия Приложения требует Согласие на аналитику, а на Устройстве нет локально сохранённого действующего Согласия именно на актуальную редакцию, MyTracker не запускается. Пользователю сначала предоставляется возможность ознакомиться с действующей редакцией Согласия и отдельно принять решение.

Это правило применяется, если локальной записи нет, Пользователь отказался от предоставления Согласия, Согласие было отозвано, локальная запись о Согласии была удалена либо сохранённая редакция не соответствует редакции, требуемой установленной версией Приложения.

Все события аналитики Приложения должны передаваться через единый программный механизм, работа которого зависит от состояния Согласия.

В Приложении не должно быть отдельного способа отправки аналитических событий в MyTracker в обход этой проверки.

Таким образом, для Приложения действует обязательное правило:

нет локально сохранённого действующего Согласия на актуальную редакцию — MyTracker не запускается — Данные аналитики не передаются.

Источник истины — состояние и редакция Согласия, а не факт первого запуска Приложения.
