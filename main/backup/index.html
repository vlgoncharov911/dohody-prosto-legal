Данные и резервные копии «Доходы Просто»

Версия 1.0.6-main-draft · обновлено 26 августа 2026

1. Назначение документа

Настоящий документ определяет порядок создания, хранения, защиты и восстановления Резервных копий в приложении «Доходы Просто», а также границы ответственности, связанные с такими копиями.

Правила доступа к созданию Резервной копии, автоматическому резервному копированию и восстановлению Данных учёта из Резервной копии в связи с FREE, PRO и 72-часовым периодом определяются Условиями PRO. Настоящий документ не изменяет Условия PRO.

2. Термины и связь с другими документами

Термины Приложение, Пользователь, Разработчик, Устройство, FREE, PRO, Подписка PRO, Данные учёта, Резервная копия, PIN-код, Биометрическая проверка, Идентификатор установки, Окончание оплаченного периода PRO и 72-часовой период используются в значении, установленном Пользовательским соглашением, Политикой конфиденциальности и Условиями PRO.

В настоящем документе дополнительно используются следующие понятия.

Внутренняя страховочная копия — внутренний механизм возврата к состоянию, сохранённому Приложением непосредственно перед восстановлением из выбранной Пользователем Резервной копии. Она создаётся как внутренняя копия текущего состояния поддерживаемых Данных учёта и настроек Приложения, хранится только внутри Приложения на Устройстве, не является Резервной копией Пользователя, не предназначена для хранения Пользователем вне Приложения, не требует пароля Пользователя и не подтверждает Подписку PRO.

Экспортированный файл — файл, создаваемый функцией экспорта Приложения. Экспортированный файл не является Резервной копией и не предназначен для восстановления Данных учёта в Приложении.

Настоящий документ применяется вместе с Пользовательским соглашением, Политикой конфиденциальности и Условиями PRO.

3. Где хранятся Данные учёта

Данные учёта хранятся локально на Устройстве.

Для использования Приложения не требуются регистрация, создание аккаунта или вход по электронной почте.

PRO не включает облачное хранение Данных учёта и не обеспечивает автоматическую синхронизацию Данных учёта между Устройствами.

Окончание оплаченного периода PRO само по себе не удаляет Данные учёта.

4. Что такое Резервная копия

Резервная копия — файл, создаваемый Приложением для последующего восстановления поддерживаемых Данных учёта и настроек Приложения.

Резервная копия может использоваться для восстановления Данных учёта на том же Устройстве либо для переноса поддерживаемых Данных учёта на другое Устройство, если соответствующий файл доступен Пользователю и Приложение может его открыть.

Резервная копия не подтверждает Подписку PRO и не заменяет подтверждение действующей Подписки PRO.

PIN-код, настройка Биометрической проверки и сведения о Подписке PRO в Резервную копию не входят.

Приложение не передаёт Резервную копию Разработчику автоматически. Пользователь может самостоятельно сохранить файл вне Приложения либо открыть системное меню отправки и выбрать способ передачи, стороннее приложение и получателя.

5. Создание Резервной копии

Пользователь может создать Резервную копию одним из следующих способов:

  • сохранить файл Резервной копии в выбранном месте хранения на Устройстве;
  • сформировать файл Резервной копии и открыть системное меню отправки. Способ передачи, стороннее приложение и получателя в этом случае выбирает Пользователь. Отдельная пользовательская Резервная копия в выбранном Пользователем месте хранения при этом не создаётся.

Создание Резервной копии доступно в PRO и в течение 72-часового периода в объёме, установленном Условиями PRO.

Если сохранение файла отменено Пользователем, такая Резервная копия не считается сохранённой.

6. Состав Резервной копии

В Резервную копию входят поддерживаемые Данные учёта и поддерживаемые настройки Приложения, относящиеся к учёту.

В Резервную копию не входят:

  • PIN-код;
  • настройка Биометрической проверки;
  • сведения о Подписке PRO;
  • пароль Резервной копии;
  • сохранённый пароль автоматического резервного копирования;
  • Идентификатор установки;
  • Внутренняя страховочная копия;
  • файлы, ранее сохранённые Пользователем вне Приложения.

Состав конкретной Резервной копии определяется версией Приложения, в которой она была создана. Настоящий документ не гарантирует включение в Резервную копию всех существующих или будущих данных и настроек Приложения.

7. Место хранения Резервной копии

При ручном создании Резервной копии Пользователь самостоятельно выбирает место хранения на Устройстве либо открывает системное меню отправки и выбирает стороннее приложение, способ передачи и получателя.

Приложение не передаёт Резервные копии Разработчику автоматически. Разработчик может получить Резервную копию только если Пользователь самостоятельно направит её Разработчику, например в составе обращения.

После сохранения или отправки Пользователем Резервной копии её дальнейшее хранение и использование зависят от выбранного Пользователем места хранения, стороннего сервиса и действий Пользователя.

Правила автоматического резервного копирования установлены разделом 9 настоящего документа.

8. Защита Резервной копии паролем

Резервная копия может быть создана с паролем Резервной копии или без такого пароля.

Если Пользователь устанавливает пароль для Резервной копии, такая Резервная копия шифруется на Устройстве. Требования к паролю Резервной копии отображаются Пользователю при его установке.

Пароль, установленный Пользователем для конкретной Резервной копии, относится только к этой Резервной копии. Такой пароль используется локально для открытия этой Резервной копии. Пароль Резервной копии не передаётся Разработчику. Удалённое восстановление забытого пароля Резервной копии Разработчиком не предусмотрено.

Средствами Приложения открыть защищённую Резервную копию без соответствующего пароля Резервной копии невозможно. Если пароль Резервной копии утрачен, для восстановления Данных учёта средствами Приложения потребуется иная доступная Резервная копия.

Резервная копия, созданная без пароля Резервной копии, не защищена шифрованием.

Изменение пароля Резервной копии при создании последующих Резервных копий не изменяет защиту ранее созданных Резервных копий.

9. Автоматическое резервное копирование

Автоматическое резервное копирование сохраняет Резервную копию в выбранном Пользователем месте хранения на Устройстве.

Включить автоматическое резервное копирование можно при наличии подтверждённой действующей Подписки PRO. В течение 72-часового периода автоматическое резервное копирование выполняется только в случае, если оно было включено до Окончания оплаченного периода PRO. Впервые включить автоматическое резервное копирование в этот период нельзя. Если автоматическое резервное копирование выключено в 72-часовой период, повторно включить его до последующего подтверждения действующей Подписки PRO нельзя.

Для использования автоматического резервного копирования Пользователь включает его, выбирает место хранения на Устройстве и при желании устанавливает пароль для автоматических Резервных копий.

Если Пользователь устанавливает пароль для автоматических Резервных копий, этот пароль используется Приложением локально при создании последующих автоматических Резервных копий. Сохранённый пароль автоматического резервного копирования хранится локально на Устройстве и не передаётся Разработчику. Этот пароль хранится отдельно от пароля, который Пользователь может устанавливать для конкретной ручной Резервной копии.

После успешного создания новой автоматической Резервной копии она заменяет предыдущую автоматическую Резервную копию. Если новая копия не была успешно создана и проверена, предыдущая сохранённая автоматическая Резервная копия не заменяется.

Ручные Резервные копии, сохранённые Пользователем самостоятельно, Приложение автоматически не удаляет и не заменяет.

Автоматическое резервное копирование может выполняться без пароля для автоматических Резервных копий, если Пользователь такой пароль не устанавливал.

10. Восстановление Данных учёта

Для восстановления Данных учёта Пользователь выбирает файл Резервной копии. Если выбранная Резервная копия защищена паролем Резервной копии, Пользователь вводит соответствующий пароль.

Перед изменением текущих данных Приложение проверяет выбранную Резервную копию.

Если пароль Резервной копии неверен, файл повреждён, недоступен либо не может быть открыт текущей версией Приложения, восстановление не начинается. Текущие Данные учёта при этом не заменяются.

Восстановление Данных учёта из Резервной копии доступно в PRO и в течение 72-часового периода в объёме, установленном Условиями PRO.

Резервная копия, созданная на другом Устройстве, может быть использована для восстановления, если файл доступен Пользователю и Приложение может его открыть. Получение доступа к PRO на другом Устройстве само по себе не переносит Данные учёта и локальные настройки.

11. Замена текущих данных при восстановлении

Восстановление выполняет замену. Текущие поддерживаемые Данные учёта и поддерживаемые настройки Приложения заменяются состоянием выбранной Резервной копии. Объединение текущих данных с Резервной копией не выполняется.

Записи и изменения, которых нет в выбранной Резервной копии, после восстановления не сохраняются.

Идентификатор установки при восстановлении не заменяется данными из Резервной копии.

PIN-код и настройка Биометрической проверки из Резервной копии не восстанавливаются. Если на Устройстве уже установлен PIN-код, восстановление Данных учёта его не отключает и не заменяет.

Настройки доставки локальных напоминаний восстанавливаются из Резервной копии, если они содержатся в выбранном файле. Если в выбранной Резервной копии таких настроек нет, текущие настройки доставки локальных напоминаний на Устройстве сохраняются.

Параметры автоматического резервного копирования, включая выбранное место хранения и сохранённый пароль автоматического резервного копирования, из Резервной копии не восстанавливаются и остаются такими, какими они были на Устройстве до восстановления.

Непосредственно перед восстановлением Приложение создаёт и проверяет Внутреннюю страховочную копию текущего состояния. Если Внутреннюю страховочную копию создать и проверить не удалось, восстановление не начинается.

Если восстановление началось и не было завершено из-за ошибки, Приложение возвращает Данные учёта из Внутренней страховочной копии, если такая копия доступна.

После успешного восстановления Пользователь может подтвердить результат либо вернуть состояние, сохранённое во Внутренней страховочной копии непосредственно перед этим восстановлением. Подтверждение результата и возврат из Внутренней страховочной копии не зависят от наличия доступа к PRO.

Внутренняя страховочная копия не заменяет Резервную копию Пользователя и не предназначена для хранения вне Приложения.

12. Несовместимая, повреждённая или недоступная копия

Приложение может отказать в восстановлении, если выбранный файл:

  • повреждён;
  • защищён паролем Резервной копии, который не совпадает с введённым паролем;
  • создан более новой версией Приложения, чем установленная на Устройстве;
  • имеет формат, который текущая версия Приложения не поддерживает.

В таких случаях текущие Данные учёта не заменяются.

Настоящий документ не гарантирует восстановление из любой ранее созданной Резервной копии во всех будущих версиях Приложения.

13. FREE и PRO

Создание Резервной копии, автоматическое резервное копирование и восстановление Данных учёта из Резервной копии относятся к PRO.

В обычном FREE указанные возможности не предоставляются, кроме 72-часового периода в объёме, установленном Условиями PRO.

14. 72-часовой период

После Окончания оплаченного периода PRO в течение 72-часового периода Пользователь может создать Резервную копию вручную и восстановить Данные учёта из существующей Резервной копии. Автоматическое резервное копирование в этот период выполняется только в случае, если оно было включено до Окончания оплаченного периода PRO. Впервые включить автоматическое резервное копирование в этот период нельзя. Если автоматическое резервное копирование выключено в этот период, повторно включить его до последующего подтверждения действующей Подписки PRO нельзя.

72-часовой период не является продолжением Подписки PRO, новым оплаченным периодом или пробным периодом.

После окончания 72-часового периода нельзя начать новую операцию создания Резервной копии или восстановления Данных учёта. Если Приложение фактически начало соответствующую операцию до окончания этого периода, уже начатая операция может быть завершена. Открытие экрана, выбор файла или иное подготовительное действие сами по себе не считаются началом операции.

15. После окончания 72-часового периода

После окончания 72-часового периода:

  • создание новой Резервной копии в Приложении прекращается до нового подтверждения действующей Подписки PRO, с учётом правила о уже начатой операции;
  • восстановление Данных учёта из Резервной копии в Приложении прекращается до нового подтверждения действующей Подписки PRO, с учётом правила о уже начатой операции;
  • автоматическое резервное копирование выключается;
  • сохранённый пароль автоматического резервного копирования удаляется;
  • ранее созданные Резервные копии, сохранённые Пользователем вне Приложения, не удаляются;
  • ранее выбранное Пользователем место хранения автоматических копий Приложением не удаляется.

Если Приложение не используется в момент окончания этого периода, выключение автоматического резервного копирования и удаление сохранённого пароля автоматического резервного копирования выполняются при следующем запуске Приложения.

Данные учёта при окончании 72-часового периода не удаляются.

16. Возвращение доступа к PRO

При последующем подтверждении действующей Подписки PRO автоматическое резервное копирование автоматически не включается. Для повторного использования автоматического резервного копирования Пользователь включает его заново и при необходимости устанавливает новый пароль для автоматических Резервных копий.

Ранее выбранное место хранения автоматических копий само по себе не включает автоматическое резервное копирование.

Защита входа в Приложение с использованием PIN-кода при возвращении доступа к PRO автоматически не включается. Правила PIN-кода определяются Условиями PRO.

17. Переустановка и другое Устройство

Переустановка Приложения или его установка на другом Устройстве сама по себе не переносит Данные учёта.

Для переноса поддерживаемых Данных учёта Пользователь использует доступную Резервную копию. PIN-код, настройка Биометрической проверки, сведения о Подписке PRO и параметры автоматического резервного копирования из файла Резервной копии не восстанавливаются.

Доступ к PRO на другом Устройстве предоставляется только при подтверждении действующей Подписки PRO в порядке, установленном Условиями PRO.

18. Удаление данных и внешние Резервные копии

Состав удаления данных Приложения определяется документом «Удаление данных».

19. Ограничения и ответственность

Если локальные Данные учёта утрачены и доступной пригодной Резервной копии нет, восстановить утраченные Данные учёта средствами Приложения невозможно.

Настоящее положение не освобождает Разработчика от обязанностей, прямо возложенных на него законодательством Российской Федерации и применимыми условиями распространения Приложения.
